# Warwick bus stops

Interactive map: https://nikmyl.github.io/warwick-bus-map/

710 physical stop positions across 11 bus services, from DfT BODS feed `20260927_024743`. Includes eight campus services and three early morning Coventry connections referenced by the University of Warwick.

The map is unofficial and is a static snapshot. Check operator timetables before travel. Temporary diversions and real-time bus locations are not included.

Contains public sector information licensed under the Open Government Licence v3.0. Map data credits OpenStreetMap contributors. Leaflet 1.9.4 provides the interactive map.
